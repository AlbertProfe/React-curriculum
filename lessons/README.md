# lessons/

One file per lesson, named `MM-LL-slug.md`:

- `MM` — module number, two digits (`01`–`05`)
- `LL` — lesson number inside the module, two digits
- `slug` — kebab-case short title

Example: `01-02-jsx-describing-the-ui.md`. The full list of planned files is in [`../CURRICULUM.md`](../CURRICULUM.md); start each one from [`../LESSON-TEMPLATE.md`](../LESSON-TEMPLATE.md).
